プライバシーポリシー

制定日：2026年6月16日 最終更新日：2026年9月17日

ニュースメイド運営者（以下「当方」といいます。）は、当方が提供するニュース閲覧アプリ「ニュースメイド」（以下「本アプリ」といいます。）におけるユーザー情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

第1条 取得する情報

本アプリでは、以下の情報を取得または保存する場合があります。

1. ユーザーが本アプリ内で保存する情報

本アプリでは、ユーザーの利便性向上のため、以下の情報を端末内に保存する場合があります。

  1. ブックマークした記事の情報

  2. 既読履歴

  3. 表示カテゴリ

  4. カテゴリの並び順

  5. 興味のある話題・興味のない話題に関する設定

  6. アプリ内の表示設定

  7. 最終更新日時

  8. その他、本アプリの機能提供に必要な設定情報

これらの情報は、原則としてユーザーの端末内に保存されます。ユーザーが設定画面でiCloud同期を有効にした場合、ブックマークした記事の識別子・見出し・配信元・リンク・公開日時、必要な著者名・ライセンス等の出典表示情報、既読記事の識別子、表示カテゴリ、興味カテゴリ、追加したRSSの設定を、ユーザー本人のiCloudプライベートデータベースに保存します。記事本文、記事画像、AI処理に使用した入力内容はiCloud同期の対象にしません。

2. ニュース取得時に発生する情報

本アプリは、RSS、公開フィード、外部ニュースサイト等からニュース情報を取得する場合があります。

この際、通信の仕組み上、ユーザーのIPアドレス、端末情報、アクセス日時等が、当方または外部ニュース配信元、外部サイト、通信事業者等により処理される場合があります。

3. 外部記事を開いた場合の情報

ユーザーが本アプリから外部ニュースサイト、広告、外部リンク等を開いた場合、当該外部サイトにおいて、Cookie、端末情報、アクセス情報、閲覧履歴、広告識別子等が取得される場合があります。

外部サイトにおける情報の取扱いについては、各外部サイトのプライバシーポリシー、利用規約、Cookieポリシー等をご確認ください。

4. お問い合わせ時に取得する情報

ユーザーが当方にお問い合わせを行う場合、以下の情報を取得する場合があります。

  1. メールアドレス

  2. お問い合わせ内容

  3. 返信に必要な情報

  4. 不具合調査に必要な端末情報、OSバージョン、アプリバージョン等

5. 広告配信に関する情報

本アプリでは、Google AdMobを利用して広告を配信します。

広告の表示、広告効果測定、不正利用防止、広告品質向上等のため、広告配信事業者が以下の情報を取得する場合があります。

  1. IPアドレス

  2. 端末情報

  3. 広告識別子

  4. アプリの利用状況

  5. 広告の表示・クリック等に関する情報

  6. クラッシュログ

  7. パフォーマンスデータ

  8. おおよその位置情報

  9. その他、広告配信事業者が定める情報

広告識別子を利用したトラッキングが必要な場合、本アプリはiOSのApp Tracking Transparencyに基づき、ユーザーに許可を求める場合があります。ユーザーが許可しない場合でも、本アプリの基本機能は利用できますが、表示される広告の内容がパーソナライズされない場合があります。

欧州経済領域、英国、スイスおよび米国の対象州等、法令上同意取得またはプライバシー選択肢の提示が必要な地域では、Google User Messaging Platformを通じて広告配信に関する同意画面またはプライバシー選択肢を表示します。必要な地域では、設定画面から選択内容を再確認・変更できます。

6. 端末内の要約・AI処理

本アプリは、利用条件により処理が認められた見出し・RSS概要等から、要約や要点などの整理情報を生成します。対応するOS・端末でApple Intelligenceが利用できる場合、AppleのFoundation Modelsを用いて端末内で処理します。利用できない場合は端末内のルールベース処理を使用します。運営者のサーバーや外部の有料AI APIへ入力を送信する機能は使用していません。Private Cloud Computeは現在無効です。ユーザー追加・利用条件未確認の配信元はAI処理の対象にしません。

生成結果は端末内に最大100件保存し、生成から7日以内の結果を再利用します。7日経過だけで保存データが削除されるわけではありません。設定画面の「すべてのローカルデータを削除」で生成結果のキャッシュも削除できます。生成結果は誤りを含む可能性があるため、元記事をご確認ください。

第2条 利用目的

当方は、取得または保存した情報を以下の目的で利用します。

  1. 本アプリの提供、維持、保護、改善のため

  2. ニュース一覧、記事詳細、要約、関連トピック等を表示するため

  3. ブックマーク、既読履歴、カテゴリ設定等を保存・表示するため

  4. アプリの不具合調査、品質改善、利用状況の確認のため

  5. ユーザーからのお問い合わせに対応するため

  6. 広告の表示、広告効果測定、不正利用防止、広告品質向上のため

  7. 利用規約違反、不正利用、セキュリティ上の問題に対応するため

  8. 法令または公的機関からの要請に対応するため

第3条 第三者サービスの利用

本アプリでは、以下の第三者サービスを利用します。

Google AdMob

本アプリでは、広告配信のためにGoogle AdMobおよびGoogle User Messaging Platformを利用します。

Googleまたは広告配信に関係する第三者が、広告配信、広告効果測定、不正利用防止、広告品質向上等の目的で、端末情報、広告識別子、IPアドレス、広告の表示・クリック情報、アプリの利用状況等を取得する場合があります。

Googleによる情報の取扱いについては、GoogleのプライバシーポリシーおよびGoogle AdMobに関する説明をご確認ください。

外部ニュースサイト・RSS配信元

本アプリは、RSS、公開フィード、外部ニュースサイト等の情報を取得・表示する場合があります。

ユーザーが外部記事を開いた場合、当該外部サイトにおける情報の取扱いは、各外部サイトのプライバシーポリシー等に従います。

Apple iCloud・CloudKit

ユーザーがiCloud同期を有効にした場合、本アプリはAppleのCloudKitを利用し、第1条に記載した同期対象データをユーザー本人のiCloudプライベートデータベースへ保存します。CloudKitにおける情報の取扱いには、Appleの利用規約およびプライバシーポリシーが適用されます。

第4条 第三者提供

当方は、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  1. ユーザーの同意がある場合

  2. 法令に基づく場合

  3. 人の生命、身体または財産の保護のために必要な場合

  4. 公衆衛生の向上または児童の健全な育成の推進のために特に必要な場合

  5. 国の機関、地方公共団体またはその委託を受けた者への協力が必要な場合

  6. 本アプリの運営に必要な範囲で、業務委託先または第三者サービスに情報を取り扱わせる場合

第5条 情報の保存期間

端末内に保存されるブックマーク、既読履歴、カテゴリ設定等は、ユーザーが本アプリ内で削除するか、本アプリをアンインストールするまで保存される場合があります。iCloud同期を有効にした場合、同期済みデータは、ユーザーが本アプリ内で対象データを削除するか、Appleが提供する方法でiCloud上の本アプリデータを削除するまで保存される場合があります。同期を無効にしただけでは、すでにiCloudへ保存されたデータは直ちに削除されません。

お問い合わせに関する情報は、対応完了後も、確認、再対応、トラブル防止等のために必要な期間保存する場合があります。

広告配信サービス、外部ニュースサイト、第三者サービスが取得する情報の保存期間については、各サービスのポリシーに従います。

第6条 ユーザーによる管理

ユーザーは、本アプリ内の設定画面または端末の設定により、以下の操作を行うことができます。

  1. ブックマークの削除

  2. 既読履歴の削除

  3. 表示カテゴリの変更

  4. 通知設定の変更

  5. 広告トラッキング許可の変更

  6. アプリのアンインストールによる端末内データの削除

  7. iCloud同期の有効・無効の変更

iOSの広告トラッキング許可については、端末の設定アプリから変更できます。

第7条 通知について

本アプリでは、保存記事のリマインド等のローカル通知を提供します。

通知を利用する場合、本アプリはユーザーに通知の許可を求める場合があります。ユーザーは端末の設定により、通知の許可、拒否、変更を行うことができます。

第8条 未成年の利用

未成年のユーザーが本アプリを利用する場合、親権者その他法定代理人の同意を得たうえで利用するものとします。

当方は、未成年者から意図的に個人情報を取得することを目的として本アプリを提供するものではありません。

第9条 安全管理

当方は、取得した情報について、漏えい、滅失、改ざん、不正アクセス等を防止するため、合理的な安全管理措置を講じるよう努めます。

ただし、インターネット通信、外部サービス、端末環境等の性質上、情報の安全性を完全に保証するものではありません。

第10条 プライバシーポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。

本ポリシーを変更する場合、当方は本アプリ内または当方が適切と判断する方法により、変更後の内容および効力発生日を表示します。

重要な変更がある場合、可能な範囲でユーザーにわかりやすい方法で通知します。
